# Avatar pack

Place the transparent PNG files from the avatar pack in this folder:

- `avatar_neutral.png`
- `avatar_happy.png`
- `avatar_sleepy.png`
- `avatar_talking.png`
- `avatar_walk_1.png`
- `avatar_walk_2.png`
- `avatar_dance.png`
- `avatar_dragged.png`

The image renderer keeps the filenames stable so future packs can replace these files without changing application code.
